# pyu-client
### An easy to use CLI made explicitly for snippets.

## NOTE: This is the _client_ software. For the server software, click [here](https://github.com/moakdoge/pyu/)

## Overview
This is the CLI for my pyu-server software. It's designed to be easy to use and easy to set up.

## Features
* Fully self contained; Doesn't rely on anything but Python's standard library.
* Full documentation for all commands.
* An in-house, optimized arg parsing library (`argplus`) designed for speed (sub 100-ms start times)
* Designed in Python for Python

## Setup
```bash
> git clone https://github.com/moakdoge/pyu-client.git
> cd pyu-client
> python3 main.py
```
